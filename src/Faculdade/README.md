# EM PORTUGUÊS 🇧🇷
# 🏫 Projeto Teórico: Sistema de Gestão Acadêmica (Faculdade)

Este diretório contém um exercício prático desenvolvido durante as aulas de Java do curso de Análise e Desenvolvimento de Sistemas (ADS). 

## 🎯 Objetivo
O foco principal deste exercício **não é a implementação de regras de negócio ou lógicas complexas**, mas sim o estudo e a aplicação de boas práticas de **organização de código, arquitetura em pacotes (packages) e modularização** em Java.

## 📂 Estrutura de Pacotes

O projeto simula a divisão de setores de uma instituição de ensino:

* **`Administracao/`**: Focado na gestão interna, contendo subpacotes para controle de cursos, financeiro e secretaria.
* **`Pessoa/`**: Destinado aos diferentes perfis de usuários do sistema, dividindo-se em alunos, coordenadores, fornecedores, funcionários, professores e visitantes.
* **`Recepcao/`**: Voltado para o atendimento diário, portaria e agendamento de horários.

# IN ENGLISH 🇺🇸
# 🏫 Theoretical Project: Academic Management System (College)

This directory contains a practical exercise developed during the Java classes of the **Systems Analysis and Development (ADS)** program.

## 🎯 Objective

The primary goal of this exercise **is not to implement business rules or complex logic**, but rather to study and apply best practices for **code organization, package architecture, and modularization** in Java.

## 📂 Package Structure

The project simulates the organizational structure of different departments within an educational institution:

* **`Administration/`**: Focused on internal management, containing subpackages for course management, finance, and the registrar's office.
* **`People/`**: Intended for the different user roles in the system, including students, coordinators, suppliers, staff members, professors, and visitors.
* **`Reception/`**: Responsible for daily reception services, front desk operations, and appointment scheduling.
