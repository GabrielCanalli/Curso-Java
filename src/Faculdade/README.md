# 🏫 Projeto Teórico: Sistema de Gestão Acadêmica (Faculdade)

Este diretório contém um exercício prático desenvolvido durante as aulas de Java do curso de Análise e Desenvolvimento de Sistemas (ADS). 

## 🎯 Objetivo
O foco principal deste exercício **não é a implementação de regras de negócio ou lógicas complexas**, mas sim o estudo e a aplicação de boas práticas de **organização de código, arquitetura em pacotes (packages) e modularização** em Java.

## 📂 Estrutura de Pacotes

O projeto simula a divisão de setores de uma instituição de ensino:

* **`Administracao/`**: Focado na gestão interna, contendo subpacotes para controle de cursos, financeiro e secretaria.
* **`Pessoa/`**: Destinado aos diferentes perfis de usuários do sistema, dividindo-se em alunos, coordenadores, fornecedores, funcionários, professores e visitantes.
* **`Recepcao/`**: Voltado para o atendimento diário, portaria e agendamento de horários.
